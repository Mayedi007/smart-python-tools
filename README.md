# 🧠 Smart Python Tools

A curated collection of smart, reusable Python tools.  
This repo includes scripts and utilities to boost productivity, automate tasks, and solve real-world problems with clean Python code.

---

## 🚀 Features

- 🔧 Handy command-line utilities  
- 🧪 Built-in testable functions  
- 📁 Organized modular structure  
- 🐍 Pure Python (no unnecessary dependencies)  
- 🛠️ Easy to extend for your own workflows  

---

## 🧰 Tools Included

| Tool Name             | Description                                         |
|-----------------------|-----------------------------------------------------|
| `exam_scraper.py`     | Scrapes examtopics.com to extract discussions       |
| `split_csv.py`        | Splits large CSV files into smaller equal parts     |
| `zip_csv_merger.py`   | Extracts CSVs from multiple ZIPs and merges them    |
| `url_cleaner.py`      | Cleans and normalizes messy URLs *(coming soon)*    |
| `json_compare.py`     | Compares two JSON files deeply *(coming soon)*      |
| `text_stats.py`       | Analyzes word/char frequencies *(coming soon)*      |

## 📦 Getting Started

```bash
# Clone the repo
git clone https://github.com/Mayedi007/smart-python-tools.git
cd smart-python-tools

# (Optional) Create a virtual environment
python3 -m venv venv
source venv/bin/activate

# Run any tool, for example:
python tools/text_stats.py example.txt
